# Coherent discourse (optional)

Use this reference when a draft is accurate but still reads like a sequence of
notes, claims, or database records. These are writing heuristics, not required
artifacts or mechanical gates.

## Build the reader's logic

Decide what question the passage answers and what the reader must understand
next. A useful research-paper progression is often:

1. establish the concrete problem and why it matters;
2. explain why existing approaches leave an important gap;
3. state the paper's central insight in plain language;
4. identify the technical challenges created by that insight;
5. explain the design choices that address those challenges;
6. present evidence in the order needed to answer the research questions; and
7. state what the evidence means and where the supported scope ends.

This is a flexible reasoning sequence, not a section template. Reorder or omit
steps when the manuscript's argument requires it.

## Form paragraphs around rhetorical purpose

Each paragraph should do one recognizable job, such as introducing a problem,
explaining a mechanism, contrasting prior work, interpreting a result, or
connecting one conclusion to the next question. Several evidence records may
support one paragraph; one record may inform several parts of the paper. Never
preserve journal order merely because it is available.

Open with the point the reader needs, develop it with enough explanation and
evidence, then end with the consequence or transition. Prefer causal links over
generic connectors. Merge fragments that repeat the same point, and split only
when the paragraph truly changes purpose.

## Keep language accessible

Use common field terminology. Define a project-specific term before using its
abbreviation or consequences. Prefer the term used consistently in
researcher-selected related papers when it accurately describes the same
concept. Do not invent labels merely to make the prose sound novel.

During revision, read the affected section as continuous prose. Ask whether a
quick but technically literate reader can follow the argument without seeing
the underlying records. If not, repair the explanation or ordering rather than
adding more metadata.
